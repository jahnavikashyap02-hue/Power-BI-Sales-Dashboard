# Power BI Sales Dashboard

## 📊 Project Overview

This project presents an interactive Power BI dashboard designed to analyze sales performance and generate meaningful business insights.

The dashboard helps users understand sales trends, profit performance, regional performance, and key business metrics.

## 🛠 Tools and Technologies Used

- Power BI
- Power Query
- DAX
- Microsoft Excel / CSV
- Data Visualization

## 📈 Key Performance Indicators

- Total Sales
- Total Profit
- Total Orders
- Profit Margin
- Sales Growth

## 🔍 Dashboard Features

- Sales analysis by region
- Monthly and yearly sales trends
- Category-wise performance
- Top-performing products
- Interactive filters and slicers
- Customer analysis

## 🚀 How to Use

1. Download the `Sales_Dashboard.pbix` file.
2. Open the file using Power BI Desktop.
3. Explore the different dashboard pages.
4. Use the filters and slicers to analyze the data.

## 📌 Key Insights

- Analyze overall sales and profit performance.
- Identify top-performing products and categories.
- Compare sales across different regions.
- Track sales trends over time.
